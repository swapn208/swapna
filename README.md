# Personal Portfolio

A clean, responsive, and modern personal portfolio website built with HTML, CSS, and JavaScript.

## Features

- **Responsive Design**: The layout adapts seamlessly to different screen sizes, ensuring a great experience on mobile devices and desktops.
- **Modern UI**: Uses CSS Flexbox and Grid for layout, along with custom variables for consistent styling.
- **Smooth Navigation**: Easy navigation across sections with smooth scrolling.
- **Interactive Elements**: Hover effects on skill cards, buttons, and navigation links.
- **Active Navigation Highlighting**: The navigation menu highlights the current section as you scroll down the page.

## Technologies Used

- **HTML5**: For the structure and semantic elements.
- **CSS3**: For styling, responsiveness, and layout (Flexbox/Grid).
- **JavaScript**: For interactive functionality.
- **FontAwesome**: For social media and skill icons.

## How to Run

1. Clone or download the repository to your local machine.
2. Open the `index.html` file in any modern web browser.
3. No server or build tools are required; it runs directly in the browser.

## Customization

- Modify the contents in `index.html` to update your personal details, skills, and education.
- Adjust the color palette and typography in the `:root` variables within `style.css`.
- Add more interactive features or animations in `script.js`.
